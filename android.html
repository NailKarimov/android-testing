What the first run found: the answer below the fold

Тест Appium с поворотом экрана упал с NoSuchElement. В альбомной ориентации результат оказывается ниже видимой части, а UiAutomator не сообщает о невидимых view. Espresso этого не заметил: recreate() не меняет ориентацию.

The Appium rotation test failed with NoSuchElement. In landscape the result is below the visible part, and UiAutomator does not report views that are off screen. Espresso did not notice: recreate() keeps the orientation.

    '.scrollIntoView(new UiSelector().resourceId("…:id/result"))')

Заодно это маленькая находка по удобству: в альбомной ориентации пользователь должен прокрутить экран, чтобы увидеть ответ, который только что запросил.

It is also a small usability finding: in landscape the user has to scroll to see the answer they just asked for.
