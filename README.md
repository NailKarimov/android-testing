# android-testing

[![Tests](https://github.com/NailKarimov/android-testing/actions/workflows/tests.yml/badge.svg)](https://github.com/NailKarimov/android-testing/actions/workflows/tests.yml)

A small Android app of our own in **Kotlin** (split the bill) with three layers of tests: JUnit on the JVM,
**Espresso** on an emulator, and **Appium** (UiAutomator2) driving the installed APK from outside — all in GitHub
Actions. Work in progress.
